# hBN phonons demo

This example obtains the phonopy `band.yaml` file on a small hBN structure using the model `mace-mpa-0-medium`. It also writes [Plumipy](https://github.com/verdi-group/plumipy)-ready files and temporary plots. Run from repo root: 

```bash
mlip-phonons --inputs demo/phonons/example1/input
```
